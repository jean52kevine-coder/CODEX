# Altéra — Premium Agency Website (Next.js 15)

## Stack
- Next.js 15 (App Router)
- React 19 + TypeScript strict
- TailwindCSS
- Framer Motion

## Commands
```bash
npm install
npm run dev
npm run typecheck
npm run lint
npm run build
```
